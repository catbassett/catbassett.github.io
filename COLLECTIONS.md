# Adding a collection through GitHub

1. Open the repository on GitHub and choose `Add file` then `Upload files`.
2. Upload the collection folder into `collection-preview/assets/images/collections/prints/` or `collection-preview/assets/images/collections/embroideries/`.
3. Name the folder with an order and URL name, for example `05-summer-garden`. It will appear as **Summer Garden** at `/collection-preview/prints/summer-garden/`.
4. Add `cover.jpg` for the category card. Add `hero.jpg` if the collection page needs a different opening image.
5. Number all gallery images: `01-painting.jpg`, `02-repeat.jpg`, `03-detail.jpg`. They display in that order at every screen size.
6. Commit the upload to `main`. The Pages workflow validates the folder and publishes the page automatically.

Only JPG, JPEG, PNG and WebP images are accepted. Folder names must use lower-case letters, numbers and hyphens after a two-digit order prefix.
